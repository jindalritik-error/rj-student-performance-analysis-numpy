# rj-student-performance-analysis-numpy
# Student Performance Analysis using NumPy

## About the Project
This project analyzes real-world student performance data using Python and NumPy. The goal is to understand student grades, study habits and academic performance through numerical analysis.

## Dataset
- Source: UCI Machine Learning Repository
- Dataset: Student Performance
- File: student-por.csv
- Total Records: 649 students
- Total Features: 33

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Google Colab

## NumPy Concepts Implemented
- NumPy Arrays
- Mean, Median and Standard Deviation
- Maximum and Minimum
- Sorting and Searching
- Boolean Indexing
- Unique Values and Frequency
- Percentiles
- Variance
- Correlation
- Statistical Analysis

## Key Findings
- Total Students: 649
- Passed Students: 549
- Failed Students: 100
- Pass Percentage: 84.59%
- Fail Percentage: 15.41%

## Project Objectives
- Practice NumPy using a real-world dataset.
- Analyze student academic performance.
- Understand statistical calculations.
- Explore relationships between study time and final grades.

## How to Run
1. Open the Jupyter Notebook.
2. Open it in Google Colab.
3. Run all cells in sequence.
4. View the analysis and visualizations.
